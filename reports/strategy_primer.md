# 策略入门（说人话版）

> 给「我玩全随机、不知道怎么形成策略」的人。三分钟读完，胜过十个带单群。

## 一句话

这个游戏**没有「能赢的策略」**。不是藏私，是数学结构封死的：
官方 40 档赔率全部 ~99%（见 `reports/payout_audit.md`），每 1 USDT 投注期望回收约 0.99 USDT。
**没有任何选号法、倍投法、节奏法能改变这一条。**

## 「策略」在这个游戏里只有 4 个旋钮

它们改变【你输钱的形状】，不改变【期望】：

| 旋钮 | 改期望？ | 实际影响 |
|---|---|---|
| 选号：随机 / 热 / 冷 / 固定 | ❌ | 无（卡方 p≈0.91，与随机不可区分） |
| 风险档：low / medium / high / classic | ❌（98.65%~99.07%） | 赔率分布形态 |
| 每局金额：平注 / 倍投 / 阶段机 | ❌ | 期望亏损随下注量放大；爆仓速度、连亏长度、肥尾 |
| 止盈止损 / 会话长度 | ❌ | 「会话收绿率」（截图率）、单次亏损规模 |

**全随机化没有错**——选号根本不进利润方程。参考赚不赚，跟选号也无关。

## 参考的截图是怎么制造出来的

不是选号神，是**会话管理**（本项目实测）：

- 赢到 +0.5 就下机截图，输了继续；
- → 68.4% 的会话能以绿色结束（「截图率」），代价是 25/30 天爆仓（`reports/daily.md`）；
- 官方表零模型重跑（`reports/sessions_official.md`，1,000 会话 × 176 局）：
  - 阶段机臂：只有 **38.2%** 会话净盈利，**中位会话 -0.42**，平均最大回撤 0.71（本金口径 1.0）
  - 参考 +0.7129 的成绩落在 **84.7 分位**——纯运气就能解释
- 也就是说：对外展示 68.4% 的绿色截图（化妆品），素颜是 38.2%（`daily` 与 `sessions` 两个口径的差别就在这里）。

## 「形成策略」的完整流程（唯一诚实版）

1. **定目标**：玩得久 / 截图好看 / 少亏 —— 三选一（互相冲突，且都不改期望）
2. **跑模拟**：`python -m keno.cli sessions`（零模型）、`daily`（全天节奏）
3. **看真实**：`collect --cdp` 采集 → `verify-rounds` 验证 → `bot --source replay` 回放
4. **自己下结论** → 从此不用信任何人的截图（包括参考，包括我）
